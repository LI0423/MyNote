# MyNote 个人知识库

这是一个涵盖计算机科学基础、软件架构、后端开发及多领域核心技术的个人学习笔记与知识沉淀仓库。

## 目录结构与内容导航

### 1. 基础理论核心
- **算法 (Algorithm)**: 涵盖常见数据结构原理与算法题解思路。
- **计算机网络 (Network)**: TCP/IP协议栈、HTTP机制与底层网络通信原理。
- **操作系统 (OperationSystem)**: 进程线程管理、内存调度机制原理探究。
- **文件系统 (FileSystem)**: 磁盘阵列、IO模型及文件存储原理。

### 2. 后端技术栈与架构
- **编程语言基础 (Language)**: 主流编程语言（如 Java 等）核心机制及高级特性。
- **Golang (Golang)**: Go 语言基础、高可用并发模型与实战特性。
- **数据库 (Database)**: 关系型与非关系型（MySQL, Redis 等）深入理解与性能调优。
- **消息队列 (MessageQueue)**: 常见消息中间件的高可用、数据流转机制及底层存储设计。
- **分布式 (分布式)**: 常见分布式理论（CAP/BASE）、共识算法及微服务相关实践。
- **设计模式 (DesignPattern)**: 软件开发架构设计原则与经典设计模式实战。

### 3. 前沿技术与大数据
- **人工智能 (ArtificialIntelligent)**: 机器学习、深度学习及相关主流框架笔记探索。
- **大数据 (BigData)**: 海量数据处理方案及相关生态组件分析。

### 4. 运维、部署与安全
- **容器化与运维 (Docker)**: Docker 核心技术与容器化部署实践。
- **服务器与网络中间件 (Tomcat & Nginx)**: Nginx 负载均衡配置原理及 Tomcat 容器工作机制。
- **安全防御 (Security)**: 常见Web安全挑战与主流安全防护手段。
- **运维与排错 (问题排查.md / Conda常用命令.md)**: 环境配置防坑指南及线上疑难杂症排查小册。

### 5. 其他
- **架构与场景设计 (场景)**: 针对特定业务场景的实战架构设计思路。
- **硬件与应用拓展 (Robot / 计组知识树)**: 计算机组成原理与特定领域拓展。
- **综合学习 (Ielts / MarkDown.md)**: 外语进阶学习打卡及文档沉淀格式规范。

致力于**系统化**构建技术体系架构。不仅包含理论知识的搬运，更注重源码级深潜以及大量底层逻辑的推演。
方便日常开发中进行图文查阅、温故知新以及复盘总结。
